EMS meter readings and run linkage

Detected EMS fields: timestamp: date_time; meter/equipment ID: meter_id; machine KWH counter: machine_kwh; master KWH: master_kwh; power: kw

EMS rows are matched to production run time windows by timestamp only; meter IDs are not assumed to map to production machine IDs. Each EMS reading's shift consumption is Machine KWH minus Master KWH. Run kWh is the change between the latest valid shift-consumption readings at or before run start and run end.

For each EMS reading, consumed kWh = Machine KWH - Master KWH. Run kWh is the change between the latest valid values at or before run start and run end; cumulative readings are not added together. The meter overview covers the EMS file's full time range, which may include periods outside production runs.

Process parameter differences

Each tag is first averaged within each linked production run, so runs with more change-triggered readings do not automatically get more weight. Standardized differences help compare tags with different units. These are associations, not proof of cause.

No group comparison is available. It requires valid process-to-run links and distinguishable efficient and inefficient machine groups.

How to interpret these results

Efficiency bands are relative quartiles of the machines in this dataset, not fixed engineering standards. Scores require complete values for output/hour (30%), scrap rate (20%), availability (20%), energy/unit (20%), and downtime rate (10%). At least two complete machines are required for scores; at least four with distinguishable scores are required for bands. Product mix and operating conditions can affect the ranking. Availability and downtime rate both reflect production loss, so the score partly weights related measures twice. Production: Durations were parsed from their explicit time format. Downtime: Durations were parsed from their explicit time format. PPC counter changes are in the run-level enriched CSV but are not score inputs. Treat findings as investigation leads, not causal conclusions or operating instructions.
